# Findory – Designvorschau

Statische Vorschau der Findory-Website mit Graphit-Petrol-Verläufen und Glasoptik.

Enthält ausschließlich die für die Website benötigten Dateien. Keine Zugangsdaten, internen Recherchen oder Projektakten.

Die Vorschau ist über GitHub Pages erreichbar. Sie enthält keine automatische Produktrecherche auf GitHub. Änderungen werden nach einem ausdrücklich ausgeführten Upload veröffentlicht.
